Connect to GitHub to save counts

Counts are saved to by committing to the repository, so you need a GitHub token that can write to it. The token stays in this browser.

  1. Create a fine-grained token.
  2. Under Repository access, choose Only select repositories and pick .
  3. Under Permissions, set Contents to Read and write.
  4. Paste it here.
